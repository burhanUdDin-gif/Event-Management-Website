# Event Horizon

A clean, minimal event management web app built with vanilla HTML, CSS, and JavaScript.
Add upcoming events, track past ones, search by name, and delete what you no longer need —
all saved locally in your browser with no backend required.

---

## What it does

- Add events with a name, date, and description
- Automatically sorts events into **Upcoming** and **Past** based on today's date
- Search events by name in real time
- Delete any event with one click
- Persists all data in `localStorage` — nothing is lost on refresh
- Includes one hardcoded sample event so the app never opens empty

---

## How to run locally

1. Clone the repository:
```bash
git clone https://github.com/burhanUdDin-gif/Event-Management-Website.git
```

2. Open the project folder and launch `index.html` in your browser.

No installs. No dependencies. No build step.

---

## How to use

1. Fill in the **Event Name**, **Event Date**, and **Event Description** fields
2. Click **Add Event** or press `Enter` to move between fields
3. Your event appears instantly in the Upcoming or Past section
4. Use the search bar to find events by name
5. Click **Delete** on any card to remove it
